# Tacticular — Build Plan

Source: `plans/17-10-2026-design.md`. Stack: TypeScript, Vite, Vitest, Canvas, pnpm, nostr-tools.
Commit after each phase.

## Layout

```
src/rules/   pure, seeded game model: data, dice, grid, sight, combat, actions, stealth, mission
src/ai/      enemy decisions: states, utility scoring
src/save/    localStorage replay save, Nostr event log
src/i18n/    EN and RU dictionaries
src/view/    Canvas render, input, HUD
test/        Vitest specs per module
```

The rules accept `Action` data and return a new `Game`. The same action list replays a game from its seed,
so the save and the Nostr log hold only actions.

## Phases

1. Rules core: grid, distance (1-2-1 diagonals), paths, sight, cover and flanking, d20 with advantage,
   damage, armor, all unit actions and abilities, statuses, turn and round flow.
   → verify: `pnpm test` covers hit math, cover, flank, AP rules, overwatch, zone of control, abilities.
2. Information and AI: vision and fog per side, concealment and detection, noise, enemy states, horn,
   reveal reaction, telegraphs, utility AI for the enemy phase and Dominate.
   → verify: tests for detection radii, silent kill, horn at round end, AI picks cover and flanks;
   a headless AI-vs-AI run ends without errors on 50 seeds.
3. Mission generation: map with cover clusters and buildings, two routes, squad of 4 of 6 classes with
   spread, 3–4 enemy groups with patrols.
   → verify: tests on 100 seeds — every floor tile reachable, groups follow composition rules.
4. Play: Canvas view with icons, previews, fog, log; EN/RU strings; localStorage replay save; signed
   Nostr events for each action.
   → verify: `pnpm build` passes; tests for replay equality and event signatures; a headless browser
   screenshot shows the map.
